## PASO 3️⃣: GENERAR API TOKEN (5 minutos)

### En Penpot Settings:

```
1. Click avatar (arriba derecha)
2. Click "Settings"
3. Busca: "API Tokens" (en left sidebar)
4. Click "+ Generate new token"
5. Name: "DealPulseHub-Automation"
6. Expiration: "Never"
7. Checks:
   ☑ teams:read
   ☑ files:read
   ☑ files:write
   ☑ projects:read
8. Click "Generate"
9. COPY el token que aparece
```

### Guardar token SEGURO:

```
CREAR ARCHIVO: C:\Users\Oscar\.env

CONTENIDO:
PENPOT_API_KEY=paste-token-aqui
PENPOT_WORKSPACE_ID=tu-workspace-id
```

**OBTENER WORKSPACE_ID:**
```
1. En Penpot, click "Mockups" project
2. URL será: app.penpot.app/dashboard/workspace/[ID-AQUI]
3. Copy el [ID-AQUI]
4. Pega en .env
```

### Resultado:
```
✅ API token generado
✅ Token guardado en .env
✅ Workspace ID guardado
```
