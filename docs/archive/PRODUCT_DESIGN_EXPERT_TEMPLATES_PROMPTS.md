### **PROMPT 3: ORDER BUMP CARD (Fast Decision)**

```
Diseña ORDER BUMP card que venda en 5 segundos.

CONTEXT:
├─ Main offer: $[XXX]
├─ Bump offer: $[XXX] (usual price $[YYY])
├─ Urgency: [Time-based / Scarcity-based]
├─ Timing: [At checkout]
└─ Audience: [Already buying = warmer than cold]

DESIGN STRATEGY:
├─ PRIMARY GOAL: Make CTA irresistible
├─ SECONDARY: Highlight value (savings)
├─ TERTIARY: Create urgency visually

VISUAL HIERARCHY:
├─ 1st (Largest): "WAIT! Add [BONUS] for just $[X]" (Red + Bold)
├─ 2nd: Value callout: "Usually $[Y], NOW just $[X]" (Green)
├─ 3rd: Brief benefits (2-3 bullets, scannable)
├─ 4th: Urgency marker (countdown timer / stock counter)
├─ 5th: CTA button (Big, contrasting color, action verb)
├─ Background: Subtle or gradient (not distracting)

COLOR PSYCHOLOGY:
├─ If urgency = RED background + contrasting CTA
├─ If value = GREEN + contrast
├─ Button: Different color entirely (Purple/Blue for contrast)

COPY ALIGNMENT:
├─ Headline: Matches copy "This is the deal you can't refuse"
├─ Benefits: 2-3 power words (transformation, bonus, exclusive)
├─ CTA: "YES, Add This Now!" or "Claim Bonus ($X)"
└─ Urgency text: "Only 3 Remaining" or "Offer expires in..."

RESPONSIVE:
├─ Desktop: Full card
├─ Mobile: Stacked, full-width button
└─ Tablet: Optimized margins

ANIMATION:
├─ Subtle pulse on CTA button (5s loop)
├─ Countdown timer (animated digits)
├─ Stock counter (decrement animation)

DELIVERABLES:
├─ Figma design (interactive prototype)
├─ Mobile + Desktop versions
├─ Button hover/press states
├─ Countdown animation spec
└─ Copy specifications

TIME: 3-4 hours
```

### **PROMPT 4: URGENCY ESCALATION (Tripwire)**

```
Diseña TRIPWIRE modal que cree urgencia máxima.

CONTEXT:
├─ Offer: $[XXX] (usually $[YYY])
├─ Time limit: [X hours/minutes]
├─ Scarcity: [X spots remaining]
├─ Positioning: "One-time offer, may not come back"
└─ Trigger: [User about to leave / Post-purchase / Specific event]

PSYCHOLOGY TARGETS:
├─ FOMO (Fear of missing out): "Offer expires in..."
├─ Scarcity: "Only 5 spots left"
├─ Exclusivity: "This is NOT available on the main website"
├─ Social proof: "1,247 people took this today"
└─ Regret avoidance: "You'll regret if you pass on this..."

VISUAL URGENCY DESIGN:
├─ Background: Full-screen overlay (modal or interstitial)
├─ Color: RED primary (urgency) + YELLOW accents (attention)
├─ Fonts: Bold, all-caps option for "ONLY", "URGENT", etc
├─ Animation: Pulsing glow on CTA, animated countdown
├─ No escape: X button small/less visible (psychological)

LAYOUT:
├─ Headline (top): "WAIT! Don't Leave" (RED, largest)
├─ Subheader: "Exclusive offer for you" (smaller, black)
├─ Offer box: Huge discount % or price (YELLOW background)
├─ Countdown timer: Animated, bold (center focus)
├─ Urgency indicators: Stock counter + social proof
├─ Benefits: 3 power bullets (what they get)
├─ CTA button: HUGE, RED or YELLOW (stands out from modal)
└─ Maybe secondary: "No thanks, I'll miss out" (gray, small)

COUNTDOWN TIMER SPECS:
├─ Format: "Offer expires in 47 minutes 23 seconds"
├─ Update: Every second (real countdown)
├─ Color: RED text, YELLOW background (high contrast)
├─ Font: Monospace, bold (feels urgent)
├─ Size: 60-80px (dominate focal point)
└─ Animation: Pulse effect (subtle breathing)

CTA BUTTON:
├─ Text: "YES, Give Me This Deal!" (action language)
├─ Color: Opposite of modal (if RED modal → YELLOW button)
├─ Size: 200px wide, 60px tall (tap-friendly)
├─ Hover: Darker shade + scale up slightly
├─ Press: Immediate feedback (state change)

RESPONSIVE:
├─ Desktop: Center modal (80% viewport)
├─ Mobile: Full-screen modal
└─ Tablet: Optimized sizing

DELIVERABLES:
├─ Figma interactive prototype (click to "buy")
├─ Countdown animation specifications
├─ Mobile + Desktop versions
├─ Button states (hover, press, disabled)
├─ Copy-design integration notes
└─ A/B variants (timer vs no timer)

CONSTRAINT: Design should feel URGENT but not scammy
TIME: 2-3 hours
```

### **PROMPT 5: DOWNSELL RESCUE OFFER**

```
Diseña DOWNSELL que rescate prospects que van a irse.

CONTEXT:
├─ Original offer: $[XXX]
├─ Downsell: $[YYY] (usually $[ZZZ])
├─ Trigger: [User clicked NO on original]
├─ Positioning: "Still want the transformation? Here's a smaller path..."
└─ Psychology: Rescue, not rejection

DESIGN STRATEGY:
├─ PRIMARY: Make rescue feel like "smart decision"
├─ SECONDARY: Highlight value (lower price = still good deal)
├─ TERTIARY: Create urgency (this offer only for decliners)

VISUAL TONE:
├─ NOT harsh (don't say "You can't afford this")
├─ YES warm (say "We have something for you")
├─ Colors: Soft blues or purples (calming, trusting)
├─ Font: Medium weight (not too bold, not timid)
├─ Background: Gradient or subtle pattern (elegant, not urgent)

LAYOUT:
├─ Headline: "Hold on! We have something better for you" (friendly)
├─ Subheader: "A faster path to the same transformation" (positive)
├─ Original offer display: "What you almost got: [Benefits]"
├─ Downsell offer box: "Here's what YOU qualify for: [Lower offer]"
├─ Price comparison: Visual (original $[XXX] / NOW $[YYY])
├─ Benefits: 3-4 key benefits (what they STILL get)
├─ CTA: "Yes, I'll take this" (affirmative, not desperate)
└─ Confidence: "You're making the right choice"

PSYCHOLOGY LEVERS:
├─ Rescue angle: "We didn't want you to leave empty-handed"
├─ Value perception: "Still get the 80% of value for 40% of price"
├─ Exclusivity: "This offer is only for people like you"
├─ Social proof: "Others in your situation chose this path"
└─ Future opportunity: "Upgrade anytime within 30 days"

COPY TONE:
├─ Understanding: "We know price was a factor..."
├─ Solution-focused: "Here's what we can do..."
├─ Confidence: "This path works just as well"
└─ Helpful: "Let's make sure you don't miss out"

CTA BUTTON:
├─ Text: "Yes, I'll take it!" or "Give me access"
├─ Color: Trustworthy blue or warm orange (not red)
├─ Tone: Positive, solution-oriented

RESPONSIVE:
├─ Desktop: Modal or page
├─ Mobile: Full-screen, stacked layout
└─ Tablet: Optimized

DELIVERABLES:
├─ Figma design (modal + page version)
├─ Mobile + Desktop
├─ Button states
├─ Copy-design integration
└─ A/B variant (more benefits vs more testimonials)

CONSTRAINT: Feel helpful, not desperate
TIME: 2-3 hours
```

### **TREE 1: "Qué estilo de diseño usar?"**

## 🧪 A/B TESTING VARIANTS

### **VARIANT PAIR 1: Color Psychology**

```
MOCKUP: Order Bump Card

VERSION A: Red + Yellow urgency
├─ Red header background
├─ Yellow "savings" callout
├─ High contrast CTA button
└─ Urgency feel: MAXIMUM

VERSION B: Blue + Green value
├─ Blue header background
├─ Green "savings" callout
├─ Softer contrast CTA button
└─ Trust feel: MAXIMUM

A/B TEST:
├─ Hypothesis: Red drives more clicks (urgency response)
├─ Metric: CTR % (click-through rate)
├─ Duration: 1 week (minimum 100 samples each)
├─ Expected winner: Version A (urgency > trust for bump)
└─ Alternative: Version B wins if audience is older (65+)
```

### **VARIANT PAIR 2: Urgency Presentation**

```
MOCKUP: Tripwire Modal

VERSION A: Animated countdown timer
├─ "47 minutes 23 seconds" - updates every second
├─ Animation: Subtle pulse
├─ Psychology: Time pressure (every second)
└─ Expected lift: +40% urgency response

VERSION B: "Offer expires TODAY" static text
├─ No countdown animation
├─ Just text statement
├─ Psychology: Deadline awareness (no second-by-second pressure)
└─ Expected lift: +20% urgency response

A/B TEST:
├─ Hypothesis: Animated countdown drives more urgency (FOMO)
├─ Metric: Conversion rate %
├─ Duration: 1 week (minimum 50 conversions each)
├─ Expected winner: Version A (animation = more urgency)
└─ Note: Monitor bounce rate (too much pressure = exit)
```

### **VARIANT PAIR 3: Copy Framing**

```
MOCKUP: Downsell Modal

VERSION A: Rescue/Loss-avoidance frame
├─ "Wait! We don't want you to go..."
├─ "Here's a faster path to the same results..."
├─ Psychology: Avoid regret (fear of missing)
└─ Tone: Helpful, understanding

VERSION B: Value/Gain frame
├─ "Smart buyers are choosing this option..."
├─ "Get 80% of the transformation for 70% less..."
├─ Psychology: Smart decision (logical benefit)
└─ Tone: Confident, value-focused

A/B TEST:
├─ Hypothesis: Loss-avoidance (rescue) drives higher conversion
├─ Metric: Downsell conversion rate %
├─ Duration: 1 week (minimum 30 conversions each)
├─ Expected winner: Version A (loss-avoidance > gain-seeking in rescues)
└─ Note: Combine winner with other winner variants
```
