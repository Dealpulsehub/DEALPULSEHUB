## 🔗 APIs & INTEGRACIONES

### **FIGMA API**

```
USE CASE: Automated design exports, asset delivery

SETUP:
1. Create Figma personal token:
   └─ Figma → Settings → Developer (left sidebar)
   └─ Click: "Create new token"
   └─ Copy token (save securely)

2. Store token securely:
   └─ Environment variable: FIGMA_API_KEY
   └─ Never commit to git

3. API endpoint examples:
   ├─ Get file: https://api.figma.com/v1/files/{file_id}
   ├─ Export images: https://api.figma.com/v1/images
   └─ Get components: https://api.figma.com/v1/components

COMMON USES:
├─ Auto-export all mockups at midnight
├─ Generate asset inventory
├─ Sync designs to asset management
└─ Automated handoff to @dev

DOCUMENTATION: https://www.figma.com/developers
```
