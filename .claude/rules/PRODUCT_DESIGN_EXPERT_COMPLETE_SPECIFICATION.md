## 🎨 VARIABLES DE DISEÑO

### **COLOR SYSTEM (Basado en Psychology)**

```
PSYCHOLOGY MAPPING:
├─ ROJO: Urgencia, acción, HOT deal
├─ VERDE: Crecimiento, gain, value
├─ AZUL: Confianza, profesional, security
├─ AMARILLO: Atención, destacado, highlight
├─ PÚRPURA: Premium, lujo, exclusividad
├─ NARANJA: Enthusiasm, energy, fun
└─ GRIS: Neutral, profesional, background

APLICACIÓN:
├─ PRIMARY: Branding + premium positioning
├─ SECONDARY: Acciones, urgencia
├─ ALERT: Urgency signals (red)
├─ SUCCESS: Value signals (green)
├─ NEUTRAL: Backgrounds, text

EJEMPLOS:
├─ Order Bump: Rojo + Verde (urgencia + value)
├─ Downsell: Azul + Gris (trust + calm)
├─ Tripwire: Rojo + Amarillo (URGENCIA MÁXIMA)
├─ Upsell: Púrpura + Verde (premium + value)
└─ Product: Azul/Púrpura + Blanco (premium)
```

### **TIPOGRAFÍA SYSTEM**

```
FONT PSYCHOLOGY:
├─ Serif: Confianza, authority, premium
├─ Sans-serif: Moderno, accesible, friendly
├─ Geometric: Futurista, fun, energetic
├─ Script: Elegante, luxury, premium

APLICACIÓN:
├─ Headline: Bold + large (atención)
├─ Body: Readable, scannable (fácil lectura)
├─ CTA: Bold, different (destaca)
├─ Support text: Smaller, lighter (secondary)

EJEMPLOS:
├─ Product Premium: Serif headline + Sans body
├─ Tech/SaaS: Geometric headline + Sans body
├─ Luxury: Script headline + Serif body
├─ Fast/Urgency: Bold Sans headline + Sans body
```

### **ESPACIADO & GRID**

```
8px GRID SYSTEM:
├─ Base unit: 8px
├─ Spacing: 8, 16, 24, 32, 48, 64px
├─ Padding: Multiples of 8
├─ Margins: Multiples of 8
└─ Gaps: Multiples of 8

RESPONSIVENESS:
├─ Desktop (1200px+): Full spacing
├─ Tablet (768-1199px): 80% spacing
├─ Mobile (< 768px): 60% spacing + stack vertical

HIERARCHICAL SPACING:
├─ Primary content: Maximum whitespace
├─ Secondary content: Medium whitespace
├─ Tertiary content: Minimal whitespace
└─ CTA buttons: Generous padding (tap-friendly)
```

### **SIZE SYSTEM**

```
CONSISTENT SIZING:
├─ Small element: 24px
├─ Medium element: 48px
├─ Large element: 96px
├─ XL element: 192px

PROPORTIONS:
├─ Golden ratio (1.618:1) for visual balance
├─ 2:3 for product mockup frame
├─ 16:9 for hero images
├─ 1:1 for product badges/icons
```

```

├─ Target: Luxury, high-ticket, expert

├─ Fonts: Serif headlines + clean fonts
├─ Images: Professional photography, minimal
├─ Layout: Generous whitespace, clean hierarchy

├─ Target: Tech-savvy, young professionals
├─ Colors: Teals, blues, vibrant accents
├─ Fonts: Geometric, modern sans-serif
├─ Images: Illustrations, geometric elements
├─ Layout: Bold typography, asymmetric balance
├─ Examples: SaaS, apps, digital products

ENERGETIC/FUN:
├─ Target: Millennial, enthusiastic, casual
├─ Colors: Bright, saturated, multiple colors
├─ Fonts: Bold sans-serif, playful
├─ Images: Vibrant, lifestyle, authentic
├─ Layout: Dynamic, playful, energetic
├─ Examples: Courses, social, lifestyle

TRUSTWORTHY/CORPORATE:
├─ Target: B2B, enterprise, serious
├─ Colors: Blues, grays, professional
├─ Fonts: Clean sans-serif, traditional
├─ Images: Professional, team photos, data
├─ Layout: Formal, structured, clear hierarchy
├─ Examples: B2B products, security, consulting

MINIMALIST/CLEAN:
├─ Target: Focus-driven, sophisticate
├─ Colors: Limited palette, blacks, grays
├─ Fonts: Single font family, minimal weights
├─ Images: Minimal or none, symbolic
├─ Layout: Ample whitespace, single focus
├─ Examples: Premium minimal products, design-focused
```

### **URGENCY VISUAL SPECTRUM**

```
NO URGENCY (Evergreen):
├─ Colors: Calm (blues, greens, neutrals)
├─ Fonts: Regular weight, normal size
├─ Layout: Spacious, breathing room
└─ Use case: Lifestyle, educational, membership

MILD URGENCY (Social proof):
├─ Colors: Warm (oranges, golds)
├─ Fonts: Medium weight, 120% size
├─ Emphasis: Testimonials, proof elements
└─ Use case: Popular products, trending

MEDIUM URGENCY (Scarcity):
├─ Colors: Warmer (reds-orange tones)
├─ Fonts: Bold weight, 140% size
├─ Emphasis: Stock counter, limited offer
└─ Use case: Exclusive offers, limited edition

HIGH URGENCY (Time-based):
├─ Colors: Red + Yellow (STOP + ATTENTION)
├─ Fonts: Bold weight, 160% size, all-caps options
├─ Emphasis: Animated countdown, "LAST CHANCE"
├─ Animation: Subtle pulse or glow
└─ Use case: Flash sales, deadline offers

CRITICAL URGENCY (Tripwire):
├─ Colors: Red + Black or Red + Yellow full intensity
├─ Fonts: Bold weight, 200% size, tight kerning
├─ Emphasis: Large countdown, scarcity counter, bold CTA
├─ Animation: Animated countdown, pulsing glow
├─ Layout: Full-screen, nothing else visible
└─ Use case: One-time offers, last-minute deals
```

## 🔗 INTEGRACIÓN CON CPS (Market Intelligence)

### **LO QUE CPS TE PROPORCIONA**

```
BUYER PERSONA DATA:
├─ Demographics (age, income, role)
├─ Psychographics (values, fears, desires)
├─ Pain points (visual angles para resolver)
├─ Motivations (what drives them)
├─ Objections (visual counterarguments)
└─ Success metrics (what they value)

CÓMO USARLO EN DISEÑO:
├─ Demographics → Font choice, language level
├─ Psychographics → Color palette, style selection
├─ Pain points → Visual "problem statement"
├─ Motivations → Visual "solution/transformation"
├─ Objections → Visual "proof/trust elements"
└─ Success metrics → Emphasize in hierarchy

COMPETITIVE INTEL:
├─ Competitor mockups (what they're using)
├─ Visual trends (industry standard style)
├─ Differentiation angles (visual unique selling points)
├─ Color palette analysis (what's working in market)
└─ Typography trends (what's resonating)

CÓMO USARLO EN DISEÑO:
├─ Analizar trends vs. diferenciación
├─ Seleccionar style que destaque (NOT copy)
├─ Mejorar lo que ves en competencia
├─ Usar color psychology diferente si needed
└─ Crear visual uniqueness
```

### **BRIEFING DE CPS → TU DISEÑO**

```
MAPEO:
CPS Input → Visual Output

"Young professionals, highly educated, Type A"
└─ → Modern sans-serif, geometric, minimal color

"Fear of missing out is primary motivator"
└─ → Scarcity visual, countdown timer, limited stock counter

"Price-sensitive but value-conscious"
└─ → Clear ROI visual, comparison chart, benefit stack

"Competitor offers 50 courses, we offer 5 specialized"
└─ → Focus on specialization visually, premium presentation

"Buying for transformation (before/after mindset)"
└─ → Before state (problem) ↔ After state (solution) visual

"Trust is highest barrier"
└─ → Testimonials prominent, credentials visible, proof elements
```
