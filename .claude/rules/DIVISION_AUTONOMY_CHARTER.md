## 🎯 DIVISIÓN CONTROL — ARBITRAJE

### **@aiox-master — Autoridad de Resolución**

```
CUANDO hay conflicto entre divisiones:

CONFLICTO EJEMPLO 1:
├─ @product-design-expert: "Quiero colores vibrantes"
├─ CXO: "Rompe brand guidelines"
├─ Solución: @aiox-master arbitra
│   └─ Propone: "Colores X es compromiso"
│   └─ Ambos aprueban → Continúa
│   └─ NO BLOQUEA el proceso

CONFLICTO EJEMPLO 2:
├─ CAO: "Video necesita 15 segundos más"
├─ Division Técnica: "Bloquea timeline"
├─ Solución: @aiox-master arbitra
│   └─ Propone: "Edd version corta + larga"
│   └─ Procede con corta
│   └─ Larga es variante post-launch

PODER:
├─ Arbitra sin bloquear
├─ Propone soluciones ágiles
├─ Escalas recursos
└─ Optimiza timeline

NO PODER:
├─ ✗ No puede rechazar trabajo de divisiones
├─ ✗ No puede hacer micro-management
├─ ✗ No puede ignorar autonomía
└─ ✗ No puede atrasar procesos
```

## 🚨 RESTRICCIONES GLOBALES (No negociables)

Todos los agentes DEBEN respetar:

```
1. DESIGN TOKENS
   └─ Colores, tipografía, espaciado definidos

2. BRAND GUIDELINES
   └─ Logo, voice, messaging

3. ACCESIBILIDAD WCAG 2.1
   └─ Contraste, captions, alt-text

4. SECURITY POLICIES
   └─ Encriptación, datos protegidos

5. PERFORMANCE STANDARDS
   └─ Videos 4K mínimo, pages < 3s load

6. ARQUITECTURA DE @architect
   └─ Stack decisions
```

Dentro de estas restricciones: **TOTAL LIBERTAD CREATIVA**
