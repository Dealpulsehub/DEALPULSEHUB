## 🎯 OPCIÓN 1: PENPOT (Recomendado para @product-design-expert)

### **Por qué Penpot es la mejor alternativa a Figma:**

```
✅ 100% GRATUITO (open-source)
✅ Web-based (como Figma)
✅ Colaborativo (como Figma)
✅ Comunidad growing (templates gratis)
✅ Diseño profesional (no toy tool)
✅ Mockups + prototyping
✅ Componentes reutilizables
✅ Exportar a cualquier formato
```

### **Setup Penpot:**

```
PASO 1: Sign up (2 minutos)
├─ Ir a penpot.app
├─ Sign up (email o GitHub)
├─ Create workspace
└─ Done

PASO 2: Instalar plugins (10 minutos)
├─ Penpot tiene plugins community:
│  ├─ Generate QR codes
│  ├─ Rename layers batch
│  ├─ Export to multiple formats
│  └─ Color generator
│
└─ Browse → Plugins → Install

PASO 3: Importar templates (5 minutos)
├─ Penpot community (gratuito)
├─ Buscar templates
├─ Duplicate workspace
└─ Ready to customize

TOTAL SETUP: 17 minutos
COSTO: $0
```

### **Penpot vs Figma (Features):**

| Feature | Figma | Penpot |
|---------|-------|--------|
| Web-based | ✅ | ✅ |
| Desktop app | ✅ | ✅ |
| Colaborativo | ✅ | ✅ |
| Comentarios | ✅ | ✅ |
| Componentes | ✅ | ✅ |
| Prototyping | ✅ | ✅ |
| Tokens design | ✅ | ✅ |
| Plugins | ✅✅✅ | ✅ (growing) |
| Costo | $144/año | **$0** |

### **Desventaja Penpot vs Figma:**

```
❌ Fewer plugins (pero creciendo)
❌ Comunidad más pequeña
❌ Menos templates pre-built
❌ Performance ligeramente más lento (pero acceptable)

Mitigation:
└─ Use Figma Community templates → Import to Penpot (copiar-pegar)
└─ Create your own templates (rápido)
└─ Join Penpot community (Discord + forum)
```

### **Workflow con Penpot:**

```
1. Create design en Penpot (web)
2. Use Penpot plugins para:
   ├─ Batch rename
   ├─ Generate colors
   ├─ Export múltiples formatos
   └─ Resize artboards
3. Export:
   ├─ SVG (para web)
   ├─ PNG/JPG (para social)
   ├─ PDF (para print)
   └─ Code (CSS/HTML snippet)
4. Share link (collaboration)
5. Invite team (free collaborators)
```

### **Integración con @product-design-expert:**

```
TOOLS INTEGRADOS EN PENPOT:
├─ Design tokens (built-in)
├─ Color system (built-in)
├─ Responsive design (built-in)
├─ Components library (built-in)
└─ Assets panel (built-in)

EXTERNAL TOOLS NEEDED:
├─ Icons: Download Phosphor Icons SVG → Drag to Penpot
├─ Photos: Unsplash.com → Download → Import to Penpot
├─ Fonts: Google Fonts → Add to computer → Use in Penpot
├─ Illustrations: Storyset.com → Download SVG → Drag to Penpot
└─ Colors: Color Hunt → Copy hex → Paste to Penpot
```
